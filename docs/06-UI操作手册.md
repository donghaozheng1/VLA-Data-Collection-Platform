## 1. 🛰 采集接入 `/collect`

### 1.1 接入磁盘上已有的数据集
| 控件 | 选什么 |
|---|---|
| 顶部「扫描目录」输入框 | 保持默认（`storage/datasets` 等已配好的根），或填你的 LeRobot 目录 |
| 结果表 | 每行一个发现的数据集（显示 robot_type / 条数 / 帧数 / fps） |

点 **「🔍 扫描磁盘」** → 对目标行点 **「接入」**（接入过的显示 **「重新接入」**）。
看到：下方「已接入的数据集」出现它，带 `v1` 与内容哈希。

### 1.2 原始轨迹转换（只对 `timestamp + joint_1..7` 的 parquet）
| 控件 | 默认值 | 说明 |
|---|---|---|
| 目录 | `C:\Users\ll\Desktop\dhz\hkc` | **只扫顶层 `*.parquet`**，不递归 |
| 名称 | `hkc-joint-7dof` | 转出的数据集名 |
| 任务文本 | `抓取放置任务（待标注）` | 写进所有 episode，之后在标注页逐条改 |

点 **「转换并接入」** → 任务类型显示「原始轨迹转换」→ 结果**只有关节、没有视频**（画布标注不可用）。

### 1.3 实时采集会话（真机 / 仿真）

## 3. 🔧 数据预处理 `/preprocess`

| 控件 | 选什么 |
|---|---|
| 数据集下拉 `#dsSel` | 源数据集（如 `sim-broken`） |
| 规则下拉 `#ruleSel` | `只保留最近一次质检通过的` / `剔除 action 全程不变的` / `只保留有成功标记的` / `全部保留` |
| 输出名 `#outName` | 可留空（自动生成） |
| 修复勾选框（7 个） | 见下表；**想严格不造数据就别勾 `resample`** |

| 勾选框 | 默认 | 作用 |
|---|---|---|
| 丢弃视频缺失/损坏的 episode | ✅ | 不可修，直接丢 |
| 跨 episode 去重 | ✅ | 轨迹近似相同只留最早一条 |
| 剔除 NaN/Inf 帧 | ✅ | |
| 剔除重复/回退时间戳的帧 | ✅ | 修时钟回退 |
| 时间戳对齐到 1/fps 均匀网格 | ✅ | 不改帧数 |
| **额外启用重采样**（线性插值补帧） | ⬜ | 会**生成中间帧** |
| 按保留帧重建视频 | ✅ | 保证 行数 == 视频帧数 |

点 **「开始预处理」**（规则类）或 **「执行修复（用上方选中的数据集）」**（修正类）。
看到：`2 → 2 条，删 1 帧，重建视频 2 个`，并在 `/data` 里出现**带血缘**的新数据集。

## 4. ✅ 数据质检 `/qc`

| 控件 | 选什么 |
|---|---|
| 数据集下拉 `#dsSel` | `pusht-2ep` |
| 按钮 | **▶ 执行质检**，结果行点 **问题明细** |

## 5. ✏️ 数据标注 `/annotation`

### 5.1 工时（先上工）
| 控件 | 选什么 |
|---|---|
| 名字输入框 `#whoInput` | 填 `张工`（默认 `admin`） |
| 按钮 | **上工** → 干完点 **收工** |

下方「👥 标注账号与工时」表看：会话数 / 未结束 / 工时 / 操作数 / 条每小时（**操作数从审计日志数**；没点收工的会话不计入工时）。

### 5.2 Episode 标注（语言 + 成功位）
| 控件 | 选什么 |
|---|---|
| 数据集下拉 `#dsSel` | `pusht-2ep` |
| 按钮 | **加载** |
| 每行三格 | **标注指令**（文本）/ **成功**（勾选框）/ **备注** |
| 每行按钮 | **保存** |

### 5.3 画布标注（**必须有视频**）
点某行的 **「画布」** → 展开卡片：

| 控件 | 选什么 |
|---|---|
| 工具单选 | `目标框（在图上拖拽）` / `关键点（点一下）` / `阶段（填帧区间）` |
| 帧 `#cvFrame` | 默认 `0`，改数字后自动换帧 |
| 起帧/止帧 `#phStart` `#phEnd` | **只在选「阶段」时出现**，默认 `0` / `10` |
| 标签 `#cvLabel` | 必填，如 `T 形块` / `插槽中心` / `接近` |
| 按钮 | **保存标注**（右侧列表可 **删除**） |

规则：坐标归一化 0~1；越界 / 宽高为 0 / 空标签 / 阶段起止反了 / 帧号超范围 → **一律 400 拒绝并说明原因**。

## 7. 📤 数据集导出 `/export`

### 7.1 先划分（卡片「📐 数据划分」）
| 控件 | 选什么 |
|---|---|
| 数据集下拉 `#spDataset` | `pusht-2ep` |
| salt `#spSalt` | 默认 `v1`（换 salt 划分就变） |
| 模式下拉 `#spMode` | `random（可复现随机）` 只写 `meta/splits.json`；`ordered（连续区间）` 同时写 `info.json` 原生 `splits` |
| 比例 | train `0.5` / val `0.25` / test `0.25`（按需改） |
| 按钮 | **执行划分** |

看到：`计数 {'train': 1, 'val': 1}`、`info.json splits={'train':'0:1','val':'1:2'}`。

### 7.2 再导出
| 控件 | 选什么 |
|---|---|
| 划分表右侧 | **导出 train(1)** / val / test（按划分导出） |
| 或通用导出：数据集下拉 `#dsSel` | `pusht-2ep` |
| 模式下拉 `#modeSel` | `全部 episode` / `只导出质检通过的` |
| 输出名 `#outName` | 可留空 |
| 按钮 | **开始导出** |

产物表点 **下载** 拿 zip。包里有：`data/chunk-000/*.parquet`、`videos/`、`meta/tasks.jsonl`（含标注指令）、`next.success` 成功位、`meta/annotations.json`（画布标注）。

## 8. 🧠 模型训练 `/training`

| 控件 | 选什么 |
|---|---|
| 扫描目录 `#rootInput` | 默认你的 `outputs` 目录 |
| 按钮 | **扫描** → 目标行 **登记** → 行内 **指标/复现** → 评估行 **逐条结果** |

- **登记**：绑定数据集版本 + 内容哈希 + 训练划分（split/salt），并生成**复现命令**
- **指标/复现**：loss 曲线 + 复现命令（末尾注明用的划分与条数）
- **逐条结果**：每个 episode 的 seed / sum_reward / 是否成功
- **bad case 回灌**：点 **「从质检/标注收集」** → 回灌目标数据集下拉 `#bcDataset` 选 `pusht-2ep` → **「回灌为困难集」**

## 10. 卡住时的对照表

| 现象 | 处置 |
|---|---|
| 按钮点了没反应 | 浏览器控制台看 `API is not defined` → 刷新页面（`platform.js` 必须在页内脚本之前） |
| 改完代码行为没变 | **重启平台**：接口与任务处理器在 import 时注册 |
| 数据集看不到 | 扫描根未包含该路径 → 加到扫描根，或先在 `/data` 确认 |
| 质检「时间戳步长」告警 | 采集抖动/丢帧 → `/preprocess` 勾 `align_ts`（或 `resample`，会造帧） |
| 质检「时间戳单调性」打回 | 时钟回退 → `/preprocess` 勾 `dedup_ts` + `align_ts` |
| 画布打不开/取帧失败 | 该数据集没有视频（纯轨迹）→ 需要带相机的采集数据 |
| 元数据写入被拒 | 数据源只读或在只读位置 → 平台库仍是权威记录，导出照常 |
| `/models` 显示未运行 | 用页面给出的命令在 `envs\yolov8n` 环境启动推理服务 |
